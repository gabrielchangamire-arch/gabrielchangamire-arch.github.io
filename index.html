02 // Projects
In Active Development · Infrastructure
Agentic AI VM System
Kept private on GitHub for security reasons. Source code and architecture walkthrough available upon request.
My goal is to build a local LLM with full agentic powers, hosted on a cloud VM that I can access from my laptop or phone via secure remote connection. I have experimented with both cloud-based agents and fully local LLMs deployed via Ollama. I see real value in strengthening local LLM capabilities for three reasons: privacy, cost, and personal agency. A local LLM with agentic abilities, running 24/7 on a VM, could execute long-running tasks autonomously without recurring API costs. Currently the Oracle Cloud ARM64 Ubuntu instance is functional with security hardening, XRDP remote desktop, and session management all working. Actively iterating.
